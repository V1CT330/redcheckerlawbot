Red Checker

An AI-powered legal information assistant focused on the Constitution, laws, and policies of the Republic of Malawi.

Red Checker allows users to ask questions about Malawian law and receive clear, accessible explanations of legal concepts, legislation, and policies.

Live App

https://redcheckerlawbot.vercel.app

Development

Requirements

You need Node.js and npm installed.

Installation

git clone <this-repository-url>
cd <repository-name>
npm install

Run locally

npm run dev

Build

npm run build

Production

The application is deployed through Vercel.
