# Red Checker

Red Checker is an AI-powered legal information assistant focused on the Constitution, legislation, and public policies of the Republic of Malawi. It is designed to make legal information easier to understand through clear, accessible explanations.

**Live application:** https://redcheckerlawbot.vercel.app

## Scope

- Answer questions about Malawian legal topics.
- Explain legal concepts and legislation in accessible language.
- Provide an AI-assisted conversational interface.
- Support a focused Malawi-law knowledge experience.

Red Checker provides legal information, not a substitute for advice from a qualified legal practitioner. Users should verify important matters against authoritative legal sources and obtain professional advice where necessary.

## Technology

The repository uses:

- React and TypeScript
- TanStack Start and TanStack Router
- Vite
- AI SDK integrations
- Supabase client libraries
- Tailwind CSS

## Getting started

### Requirements

- Node.js
- npm

### Install dependencies

```bash
npm install
```

### Run locally

```bash
npm run dev
```

### Build

```bash
npm run build
```

### Lint

```bash
npm run lint
```

## Deployment

The production application is deployed through Vercel. Configure required AI-provider and backend environment variables in the deployment environment. Do not commit API keys or privileged credentials.

## Responsible use

- Do not present generated responses as formal legal opinions.
- Prefer primary legislation and authoritative sources.
- Clearly communicate uncertainty or missing legal context.
- Do not fabricate statutes, cases, citations, or legal requirements.
